**1.3 Typography**

*   Primary Heading Font: Clash Display, Syne, or Plus Jakarta Sans Bold — conveys premium authority
*   Body Font: Inter or DM Sans — clean, highly readable, modern
*   Accent / Highlight: Same heading font in Gold (#FFB800) for key phrases

_📌 Import fonts from Google Fonts or purchase Clash Display. Fallback: system-ui, sans-serif._

**1.4 Overall Design Direction**

The site must feel: premium, globally credible, data-confident, and conversion-focused. Reference Propellic.com for the travel niche confidence and LapaOne.com for the full-service Indian agency structure. Not too corporate, not too flashy — clean luxury.

*   Theme: Dark hero + light interior sections + dark footer
*   Motion: Subtle scroll-triggered fade-ins, number counters on stats, smooth hover states on cards
*   Layout: Wide whitespace, generous padding, max-width ~1280px centered
*   Mobile-first: All sections must be fully responsive. CTA buttons always visible above fold on mobile
*   Performance: Target Lighthouse score 90+ on Performance, Accessibility, SEO

**03 — TECHNICAL SPECIFICATIONS**

**3.1 Tech Stack**

*   Framework: Next.js 14+ with App Router
*   Language: TypeScript (preferred) or JavaScript
*   Styling: Tailwind CSS — use custom theme config for brand colors
*   Animation: Framer Motion for scroll animations and transitions
*   Form Handling: Formspree (easiest) or custom Next.js API route with Nodemailer
*   Analytics: Google Analytics 4 + Meta Pixel (both REQUIRED from day 1)
*   Fonts: Google Fonts (Plus Jakarta Sans + Inter) or Clash Display (local)
*   Icons: Lucide React or Phosphor Icons
*   Deployment: Vercel (recommended) — connect to GitHub for CI/CD

**3.2 SEO Requirements**

*   Meta title + description on every page (dynamic via Next.js Metadata API)
*   Open Graph tags for social sharing (image, title, description)
*   Structured data (JSON-LD): LocalBusiness + ProfessionalService schema
*   Sitemap.xml auto-generated
*   Robots.txt configured
*   All images: WebP format, proper alt text, lazy loading
*   Core Web Vitals: LCP < 2.5s, CLS < 0.1, FID < 100ms

**3.3 Integrations Required**

*   WhatsApp CTA: wa.me/91XXXXXXXXXX links throughout (floating button on mobile)
*   Calendly / Cal.com embed for booking (modal or inline)
*   Google Analytics 4 — GA4 property ID to be provided by Yash
*   Meta Pixel — Pixel ID to be provided by Yash
*   Contact form backend: Formspree or custom API
*   Google Tag Manager (optional but recommended for future flexibility)

**3.4 Performance & Quality**

*   Lighthouse scores target: Performance 90+, Accessibility 90+, SEO 95+, Best Practices 95+
*   Fully responsive: Mobile (320px+), Tablet (768px+), Desktop (1024px+), Wide (1440px+)
*   Cross-browser: Chrome, Firefox, Safari, Edge (latest 2 versions)
*   No layout shift on load — all images with defined width/height
*   Font display: swap — prevent invisible text during load
